## An editor

To make programming the Sync8 and future CHIP8 projects easier, I have
written an editor in TCL/TK. Here's a screen shot of the main editor.

![]({{site.baseurl}}/images/chip8/ChipEdit.png)

There is a main edit window where the CHIP8 opcodes can be entered. These
are auto capitalized and highlighted acording to groups. The command is 
also decoded with the function shown along with address for jumps and 
registers if any. Both the highlighting and decode works well but because
I'm not actully processing the entier opcode, data will give ambigious
results. But it's still very helpful for programming.

To the left of the edit window is the address window. This will display
the address starting at 0x200 and will skip both comment lines starting 
with // and label line which start with #. Both of these are ignored in
the HEX upload. 

To the right of the edit window is a scratch pad. This is an area to write
notes such as registers and useage. This area is not saved to the project
but is mainly used to keep from haveing the look back to figure out what
simething is used for.

The lower section is the serial console. Here all serial traffic can be
displayed. The serial port and speed can be set with the drop down. You
can connect to the chosen serial port with the connect button. Pressing
the upload HEX will process and transmit the current file in the main
editor.

Under the file memu you can do a New which will clear the edit window, 
you can save and load a porject, which saves or loads a text file that
has all the comment lines. You can save a HEX file. This will output a
text file that processes the current edit file into bytes and puts them
into an array ready to be used in a C++ program. You can also load a 
binary ROM file.

The navigate button will open a window that you can enter a hex address
and the editor will jump to that address and highlight the line.

Under the Help menu is an about and a opcode popup window that list the
CHIP8 opcodes.

## The Pixel Editor

Finaly, there is a pixel editor.

![]({{site.baseurl}}/images/chip8/SpriteEdit.png)

This is full screen sprite editor. You can select between 8x8, 16x16,
32x32 or 64x32. The preview window and byte columns will adjust for
each choise. The copy button will process the bytes into 16 bit hex
for use in the editor by using ctrl-v.
