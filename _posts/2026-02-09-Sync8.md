## A CHIP8 interpreter on a MEGA

![]({{site.baseurl}}/images/chip8/arduino_mega_2560.webp)

Welcome to my blog about getting a CHIP8 interpreter running on an 
unmodified arduino Mega 2560. The 8k of sram is enough for the CHIP8's
need of 4k memory and the clock of 16 mHz is fastest enough for the 64x32
pixel display in composite video.

There are plenty of sites that tell what CHIP8 is and how it works, so I'll
just start right off with getting it working on the mega.

## The composite video
To get the video working I'll use Timer1 in PWM mode and link pin PD11 as 
output for the horizontal sync pulse. The ISR is used as the pixel clock
with the output on pin PD29 which is pin 7 of PORTA. I could use a couple 
of resistors as in the TVOut display but decided to use a simple video
amp for better stability.

![]({{site.baseurl}}/images/chip8/Video Amp.png)

I used <avr/sleep.h> to put the procrssor to sleep between interrupt calls
on the h_sync. This reduces the video jitter to near zero. While the pixel
clock is in the blanking period, there is still one cycle through the main
while loop. If the cpu clock is high, one cycle through the cpu will run
before going to sleep. This sets the main system speed at 15.7 kHz.

The h_sync interrupt also triggers a pin interrupt on the falling pulse.
This gives apox 4.5 uS between the start and finish of the sync pulse. 
This period is used for incrementing the CPU clock and setting the bool.

```cpp
ISR(PCINT0_vect, ISR_NAKED)
{
  asm volatile(
    "push r16               \n\t"
    "in   r16, %[sreg_reg]  \n\t"
    "push r16               \n\t"
    "push r17               \n\t"

    "sbic %[pin_reg], 5     \n\t"   // Skip if Pin 11 (PB5) is High (we want falling)
    "rjmp  exit_%=          \n\t"

    "lds  r16, (sys_clock)  \n\t"
    "inc  r16               \n\t"
    "sts  (sys_clock), r16  \n\t"

    "lds  r17, (sys_speed)  \n\t"
    "and  r16, r17          \n\t"
    "brne exit_%=           \n\t"

    "ldi  r16, 1            \n\t"
    "sts  (sys_cpu_clock), r16 \n\t"

    "exit_%=:               \n\t"
    "pop  r17               \n\t"
    "pop  r16               \n\t"
    "out  %[sreg_reg], r16  \n\t"
    "pop  r16               \n\t"
    "reti                   \n\t"   // REQUIRED: NAKED ISRs must end with reti
    :
    : [pin_reg]  "i" (_SFR_IO_ADDR(PINB)),
    [port_reg] "i" (_SFR_IO_ADDR(PORTE)),
    [sreg_reg] "i" (_SFR_IO_ADDR(SREG))
    : "r16" , "r17", "memory"
  );

}
```
The pixel clock is just a series of loads, shifts and out. Instead of trying to
just set one pin, the whole port is used with the pixel data being taken from
bit 7. Here is a snipet of the pixel clock asm code.

```cpp

      // =============================================
      //      Back Porch
      // =============================================
      "ldi  r16, 61   \n\t"
      "dly_%=:        \n\t"
      "dec  r16       \n\t"
      "brne dly_%=    \n\t"
      "nop            \n\t"
      "nop            \n\t"
      // ==============================================
      //      Pixel Clock
      // ==============================================

      "ld  r16, z+     \n\t"
      "out %0, r16     \n\t"
      DELAY_A
      "lsl r16         \n\t"
      "out %0, r16     \n\t"
      DELAY_A
      "lsl r16         \n\t"
      "out %0, r16     \n\t"
      DELAY_A

      "out %0, r16     \n\t"
      DELAY_A
```

The vertical sync is handled useing a large switch statment. The vertical
sync pulse is done by inverting h_sync pin from scan lines 255 to 261.

```cpp
    case 255:
      /* V_Sync Start   */
      /* Invert the pin */
      TCCR1A &= ~(1 << COM1A0);

      if (chip8.dt > 0x00)
      {
        chip8.dt --;
      }

      if (chip8.st > 0x00)
      {
        chip8.st --;
        sys.sound_on = true;
      } else {
        sys.sound_on = false;
      }
      break;
    case 261:
      /* Reset the counts  */
      pixel_clock.line_count = 0;

      pixel_clock.ram_line = 0;

      pixel_clock.line_repeat = 0;

      /* V_Sync End     */
      /* Invert the pin */
      TCCR1A |= (1 << COM1A1) | (1 << COM1A0);

      break;
```

Also during this time, the sound timer and delay timers are handled. This set
their time at 60 Hz.

## The keyboard

For the prototype, I used a simple 4x4 matrix keyboard. The keyboard is connected to
PORTC on pins PD30 to PD37. The columns are connect to C4 to PD37, C3 to PD36, C2 to 
PD35 and C1 to PD34. The rows are connected to R1 to PD33, R2 to PD32, R3 to PD31 and
R4 to PD30. Each row pin is connected to Vcc a 10k resistor.

## The sound

The sound timer on and off is handled in the h_sync ISR but instead of switching a pin
on and off in the ISR, which didn't sound good, I used Timer4 in PWM node with 50%
duty cycle. 

```cpp
void begin()
{
    pinMode(7, OUTPUT);
    
    // Reset Timer 4 control registers
    TCCR4A = 0;
    TCCR4B = 0;

    // Set Mode 14: Fast PWM with TOP = ICR4
    TCCR4A |= (1 << WGM41);
    TCCR4B |= (1 << WGM42) | (1 << WGM43);

    // Set initial frequency (e.g., 440Hz)
    // Formula: TOP = (Clock / (Prescaler * Frequency)) - 1
    // (16,000,000 / (64 * 440)) - 1 = 567
    ICR4 = 359;

    // Set 50% duty cycle (Volume/Square wave symmetry)
    OCR4B = ICR4 / 2;

    // Set Prescaler to 64 (balanced for audible frequencies)
    TCCR4B |= (1 << CS41) | (1 << CS40);

    // Ensure sound is OFF initially
    TCCR4A &= ~(1 << COM4B1);  
}
```

This makes a nice 440 Hz beep with posibale upgrades later to add musical tones if
I want to. The output from PD7 is sent to a LM386 audio amp and mini speaker.

## The CPU reset

Once the CHIP8 program is up and running, I wanted a way to restart the program
without reseting the Mega. I have setup an interrupt on pin PD2 which is interrupt 4.
The pin in connected to Vcc thru a 10k resistor.

```cpp
  /*
      Set PD4 as INPUT for reset interrupt pin
  */
  DDRE &= ~_BV (4);

  /*
      Attach an interrupt function
  */
  attachInterrupt(digitalPinToInterrupt(2), cpu_reset, FALLING);
```
In the ISR, a bool is set and on the next h_sync return the sys.reset will run.

```cpp
    if (sys.reset == true)
    {
      /*
        Clear the screen
      */
      clear_screen();
      /*
          Reset the program counter
      */
      chip8.pc = PROGRAM_OFFSET;
      /*
        Clear the waiting for key
      */
      waiting_for_key = false;

      /*
          Clear the bool
      */
      sys.reset = false;
    }
```
## Other pins 

PD8 and PD9 are used to set the CPU speed. Both are pulled low through a 10k
resistor to GND. If both pins are low the CPU speed is aprox 660 Hz. If PD8
is high the CPU speed is aprox 360 Hz and if PD9 is high the CPU speed is 
aprox 1200 Hz. Both pins high is not handled as these are connect to an
On/Off/On switch, so center would be normal (660 Hz) speed. Pins PD48 and PD49
are connected to a dual Red/Green LED to show speed set.

PD38 is the Run/Program switch. In the run positon, the CPU runs the current
program. In the program position, the mega is setup to receive a HEX program
sent over the Serial. The stream of HEX bytes is stored in the CHIP8 memory
starting at 0x200. Switching back to run and pressing reset will then run 
the downloaded program. There is dual Red/Green LED connected to PD46 and 
PD47 for showing run, Green or program, Red mode.

There is also an LED on PD13 which is on when a key is pressed and off when
a key is not pressed..
